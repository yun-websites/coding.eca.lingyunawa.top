# Lesson 03 - 让程序做决定：条件与循环

## 章节定位

这是 Coding Club 的第三节正式课。学生已经能够接收输入、转换数据并使用基础容器；本节开始学习让程序根据数据作出不同反应，并让一段代码重复执行。

本节把 `if`、`elif`、`else` 与 `for`、`while` 放在同一个“控制程序流程”主题下。条件决定程序走哪条路，循环决定程序重复做什么。课程以一个互动挑战程序收束，让学生把输入、比较、分支和重复结合起来。

## 本节概览

| 项目 | 内容 |
|---|---|
| 建议时长 | 60 分钟 |
| 主题 | 比较运算、`if`/`elif`/`else`、`for`、`range()`、`while` |
| 核心产出 | 一个带选择和重复互动的 Challenge Program |
| 先备知识 | 能运行 Python，使用变量、`input()`、`int()` 和列表 |
| 下一节衔接 | 把重复逻辑整理成函数，减少重复代码 |

## 学习目标

到课末，学生能够：

1. 使用 `>`, `<`, `>=`, `<=`, `==`, `!=` 比较数值或文字。
2. 写出带有正确缩进的 `if`、`elif`、`else` 结构。
3. 解释条件为 `True` 或 `False` 时程序会执行哪一段。
4. 使用 `for` 遍历列表或 `range()` 生成的一组数字。
5. 使用 `while` 在条件成立时重复运行，并用计数器或输入改变循环状态。
6. 结合输入、条件和循环完成一个能运行到结束的小程序。

## 成功标准

- 程序至少使用一次比较运算和一组 `if`/`elif`/`else`。
- 程序至少使用一次 `for`，并遍历列表或 `range()`。
- 程序至少使用一次 `while`，循环有明确的结束条件。
- 程序至少接收一次用户输入，并根据输入产生不同结果。
- 程序运行时没有无限循环，输出能说明每一步发生了什么。
- 学生能指出每个条件、循环体和缩进层级。

## 教学重点与边界

| 重点 | 本节做法 |
|---|---|
| 条件结构 | 先预测条件真假，再运行并逐行观察分支。 |
| 缩进 | 强调同一代码块必须保持一致缩进；条件后面需要冒号。 |
| `for` | 只遍历列表和 `range()`，不展开复杂迭代器。 |
| `while` | 使用计数器或明确变化的输入，专门演示如何避免无限循环。 |
| 分层支持 | 需要支持的学生使用起步模板；提前完成者增加分支或调整循环次数。 |

本节暂不展开：函数、嵌套循环、`break`/`continue`、异常处理、复杂布尔表达式和全面的算法分析。

## 形成性评估

- 课堂中：预测条件结果、判断分支、追踪循环次数。
- 中段检查：学生独立写出一个年龄分类器和一个 `for` 循环。
- 课末：运行 Challenge Program，并完成 4 题 exit ticket。
- 记录：将学生标记为“独立完成 / 在提示后完成 / 尚需支持”，供下一节函数课分组使用。
