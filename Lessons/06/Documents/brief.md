# Lesson 06 - Python 的有趣角落：先猜，再运行

## 章节定位

这是 Coding Club 的第六节课。本节不引入新的语法主题，也不要求学生记忆新的库；学生用已经学过的变量、表达式、条件、函数和 `print()`，观察 Python 中一些容易出乎意料、但可以用规则解释的行为。

核心课堂习惯是：**先独立预测，再运行验证，最后解释原因**。重点不是把所有规则背下来，而是学会拆解表达式、检查优先级，并用小实验验证自己的想法。

## 本节概览

| 项目 | 内容 |
|---|---|
| 建议时长 | 60 分钟 |
| 主题 | 布尔值、比较链、优先级、真假值、运算符返回值、对象相等性 |
| 核心产出 | Python Prediction Quiz（预测题小测/趣味实验） |
| 先备知识 | 变量、数字和字符串、`if`、函数、`print()`、基本运算符 |
| 下一节衔接 | 继续使用表达式和条件解决更大的问题 |

## 学习目标

到课末，学生能够：

1. 把 `True` 和 `False` 当作布尔值使用，并理解它们在数字运算中的行为：`True` 相当于 `1`，`False` 相当于 `0`。
2. 解释比较链，例如 `a < b < c` 相当于两个比较条件同时成立，而不是普通的从左到右拼接。
3. 按优先级拆解 `True < False + False > True`，并预测其结果为 `False`。
4. 区分 `=`、`==` 和 `is` 在示例中的不同作用；本节只要求知道 `is` 是“是否为同一个对象”的检查。
5. 通过运行小实验验证预测，并用清晰的文字说明结果。
6. 发现 Python 代码“看起来很短”时，主动加括号或拆成多行让意图更清楚。

## 成功标准

- 能在运行前完成至少 6 道预测题。
- 能正确解释示例 `True < False + False > True`。
- 能指出比较链中的两个比较条件。
- 能用变量或分步代码验证至少一个猜想，而不是只看最终输出。
- 能说出至少一条“有趣但不建议滥用”的 Python 写法，并给出更清楚的版本。
- 小测代码可以运行，预测和实际结果都被记录。

## 教学边界

本节不展开：

- Python 数据模型和魔术方法；
- CPython 实现细节或内存地址；
- 复杂的对象可变性理论；
- 依赖实现细节的整数缓存；
- 把“代码能运行”误认为“代码容易读”。

## 教学重点与提醒

| 观察点 | 教师提醒 |
|---|---|
| `True + False` | 布尔值可以参与数字运算，但业务代码中不要依靠这种隐式转换来制造困惑。 |
| `a < b < c` | 这是一种合法且常见的区间判断；强调它等价于 `a < b and b < c`。 |
| `and` / `or` | 它们会短路，且表达式可能返回操作数本身；只做直观演示，不深入实现。 |
| `==` / `is` | `==` 比较值，`is` 比较是否为同一个对象；本节不讨论整数缓存等实现细节。 |
| 奇技淫巧 | 趣味代码用于提问和调试，不代表生产代码应追求最短。 |

## 形成性评估

- 每个例子先投票预测，再运行；要求学生说出“哪条规则导致结果”。
- 中段让学生把一行难读表达式拆成多个有名字的步骤。
- 课末完成 Prediction Quiz，记录预测、实际输出和解释。
