# Lesson 01 - 让 Python 说话：输出、字符串与变量

## 章节定位

这是 Coding Club 的第一节正式课。课程从“运行一段代码并看懂输出”开始，建立最基本的程序阅读、编辑、运行和报错修正习惯。学生将在一节课内完成一个可展示的个人欢迎卡程序。

诊断数据显示，班级起点差异明显：多数学生从未使用 Python，只有少数学生能完成函数和综合编程题。因此本节课不假设任何既有经验，先把“代码是什么、如何运行、如何得到准确输出”讲扎实；对已有经验的学生提供不改变主线的扩展任务。

## 本节概览

| 项目 | 内容 |
|---|---|
| 建议时长 | 60 分钟 |
| 主题 | `print()`、字符串、变量、变量命名 |
| 核心产出 | 一个使用至少两个变量的个人欢迎卡程序 |
| 先备知识 | 无 |
| 使用工具 | 已配置 Python 3 的编辑器或在线 Python 环境 |
| 下一节衔接 | `input()`、数值与简单的输入-处理-输出程序 |

## 学习目标

到课末，学生能够：

1. 运行 Python 文件，并区分代码编辑区与输出区。
2. 用 `print()` 输出文字、数字和变量的值。
3. 把文字写成带引号的字符串，并读懂常见的 `SyntaxError`、`NameError`。
4. 创建和使用变量，说明变量名的三条基本规则。
5. 独立完成并展示一个个人欢迎卡程序。

## 成功标准

学生的程序满足以下条件即达到本节目标：

- 能运行且没有报错。
- 使用至少两次 `print()`。
- 定义并使用至少两个有意义的变量。
- 输出内容与代码意图一致，文字使用英文引号。
- 能解释一个变量保存的是什么信息。

## 教学重点与应对

| 诊断发现 | 本节应对 |
|---|---|
| 很多学生会描述输出，但不能准确写出输出格式 | 每个示例都要求先预测，再运行，再逐行核对。 |
| 变量命名题正确率低 | 用“可读、合法、有意义”的三步检查和短练习反复巩固。 |
| `input()` 概念薄弱 | 本节只作为可选预览，不与类型转换或条件判断混教。 |
| 一名学生明显领先 | 给予格式化输出、额外字段和自定义版式扩展，不让其代替他人完成代码。 |

## 形成性评估

- 课堂中：预测输出、变量名分类、两次教师巡视检查。
- 课末：提交欢迎卡程序并完成 3 题 exit ticket。
- 记录：将学生标记为“独立完成 / 在提示后完成 / 尚需支持”，供下一节分组使用。
