# Homework 01: Python Welcome Card Worksheet

## Goal

Use what you learned in Lesson 01 to write, test, and explain a short Python program. Your program will introduce you with variables and `print()`.

Complete the worksheet first, then build the matching PDF in this project.

## What You Will Practise

- Use `print()` to show text, numbers, and variable values.
- Put text inside matching English quotation marks.
- Create clear, legal variable names.
- Predict program output before running the code.
- Find and fix a simple `NameError` or `SyntaxError`.

## Your Tasks

### 1. Fix the Errors

For each line in the worksheet PDF:

1. Identify whether the problem is a missing quotation mark, missing parenthesis, or an undefined name.
2. Write a corrected line of Python.

### 2. Plan Your Variables

Choose at least two pieces of information about yourself. Complete the variable map with:

- a legal variable name;
- the value you will store; and
- what that value means.

Variable names must not contain spaces or hyphens, and cannot begin with a number.

### 3. Write Your Welcome Card Program

Write a Python program that:

- creates at least two meaningful variables;
- uses at least three `print()` calls;
- prints one welcome message;
- prints at least one variable value; and
- uses matching English quotation marks around every string.

### 4. Predict and Test

Before running the program, write the exact output you expect, one line at a time. Then run your code and tick the self-check items after correcting any differences.

### 5. Explain One Idea

Answer the exit question in one or two sentences:

> Why do `print(city)` and `print("city")` give different results?

## Deliverables

Submit both of the following:

1. A completed `lesson-01-python-homework.pdf` downloaded from this app.
2. Your Python source file, named `welcome_card.py`.
