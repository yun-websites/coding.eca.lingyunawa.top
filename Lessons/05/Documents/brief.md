# Lesson 05 - 借用 Python 的工具：模块与库

## 章节定位

这是 Coding Club 的第五节正式课。学生已经学习变量、输入、条件、循环和函数；本节开始使用别人已经写好的代码。学生会先理解“模块是保存代码的 Python 文件”，再练习从标准库导入模块和函数，最后把 `random` 与自己的函数结合，完成一个随机挑战程序。

本节把 `import` 看成“把工具箱带进程序”，把 `from ... import ...` 看成“只拿工具箱中的某件工具”。重点不是背诵很多库，而是建立导入、调用和查错的基本习惯。

## 本节概览

| 项目 | 内容 |
|---|---|
| 建议时长 | 60 分钟 |
| 主题 | 模块、标准库、`import`、`from ... import ...`、命名空间 |
| 核心产出 | Random Challenge（随机挑战程序） |
| 先备知识 | 能运行 Python，使用变量、条件、循环和函数 |
| 下一节衔接 | 使用模块拆分自己的代码，或进一步学习文件和数据 |

## 学习目标

到课末，学生能够：

1. 解释模块、库和函数之间的基本关系。
2. 使用 `import module` 导入标准库模块。
3. 使用 `module.function()` 调用模块中的函数。
4. 使用 `from module import function` 导入指定函数。
5. 区分 `import random` 与 `from random import randint` 的调用写法。
6. 选择不容易与模块或函数冲突的变量名。
7. 结合导入的工具和自定义函数完成一个随机互动程序。
8. 根据 `ModuleNotFoundError`、`NameError` 或属性错误检查导入和调用代码。

## 成功标准

- 程序至少正确使用一次 `import module`。
- 程序至少正确使用一次 `from module import function`。
- 学生能指出导入的模块或函数来自哪里。
- 程序能调用 `random` 中的工具并产生不同结果。
- 至少定义一个自己的函数，并在程序中调用。
- 不把 `random`、`math`、`randint` 等工具名覆盖成变量。
- 程序从头运行到结束，没有未解决的导入或调用错误。

## 教学重点与应对

| 诊断风险 | 本节应对 |
|---|---|
| 把 `import` 当成函数调用 | 先画“导入工具箱 -> 用点号找到工具”的流程。 |
| 忘记模块名前缀 | 反复对比 `random.randint(1, 6)` 与 `randint(1, 6)`。 |
| 认为导入后所有函数都可以直接写 | 明确说明 `import random` 后需要 `random.` 前缀。 |
| 变量名覆盖工具名 | 演示为什么不要写 `random = 5` 或 `randint = 10`。 |
| 把外部第三方库和标准库混在一起 | 本节只使用 Python 自带的 `random`、`math` 和 `time`，不安装新库。 |

## 教学边界

本节暂不展开：

- `pip` 和第三方库安装；
- 自己发布 Python 包；
- 相对导入和包目录；
- `__name__ == "__main__"`；
- 模块的循环导入；
- 随机数的安全性或伪随机算法原理。

## 形成性评估

- 课堂中：预测导入后的调用写法、匹配模块与函数、修复导入错误。
- 中段检查：学生独立写出 `import math` 和 `from random import randint` 的示例。
- 课末：运行 Random Challenge，并完成 4 题 exit ticket。
- 记录：将学生标记为“独立完成 / 在提示后完成 / 尚需支持”，供下一节模块拆分或文件课分组使用。
