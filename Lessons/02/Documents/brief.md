# Lesson 02 - 变量工具箱：输入、类型与数据处理

## 章节定位

这是一个相对独立的变量入门课。学生不需要把 Lesson 01 的欢迎卡继续改造，而是直接学习：程序如何接收信息、变量如何保存不同类型的数据，以及如何对这些数据做最基本的读取、修改和组合。

课程以一个独立的“个人数据档案”任务收束。学生会使用 `input()` 收集资料，用 `int()` 和 `float()` 转换数字，并把资料分别放进字符串、整数、浮点数、列表、字典和元组中。

## 本节概览

| 项目 | 内容 |
|---|---|
| 建议时长 | 60 分钟 |
| 主题 | `print()`、`input()`、变量类型、基础变量处理 |
| 覆盖类型 | `str`、`int`、`float`、`list`、`dict`、`tuple` |
| 核心产出 | 一个独立的 Personal Data Dashboard（个人数据档案） |
| 先备知识 | 能运行 Python，知道字符串需要引号，能进行简单变量赋值 |
| 下一节衔接 | 条件判断、比较运算和根据数据作出选择 |

## 学习目标

到课末，学生能够：

1. 使用 `print()` 显示文字、变量和简单计算结果。
2. 使用 `input()` 获取用户输入，并知道输入默认是 `str`。
3. 使用 `int()` 和 `float()` 把可转换的输入变成数字。
4. 识别并创建 `str`、`int`、`float`、`list`、`dict` 和 `tuple`。
5. 对变量进行基础处理：重新赋值、连接字符串、计算数字、读取列表/字典/元组中的内容。
6. 独立完成一个同时使用多种变量类型的小程序。

## 成功标准

- 使用至少两次 `input()`，其中至少一次输入被转换为 `int` 或 `float`。
- 程序中明确使用六种目标类型各至少一个：`str`、`int`、`float`、`list`、`dict`、`tuple`。
- 至少进行一次数字计算、一次列表操作和一次字典读取或更新。
- 至少使用两次 `print()` 展示处理后的结果。
- 程序能从头运行到尾；输入符合提示时没有报错。
- 学生能解释 `input()` 的结果为什么需要转换，以及列表、字典、元组分别保存什么。

## 教学边界

本节只做类型的“认识和基础使用”，不展开：

- `if`、`for`、`while` 或函数
- 列表切片、嵌套数据结构和复杂方法
- 异常处理和不合法输入的处理
- 类型之间的全面转换规则

学生可以先把六种类型看成六种不同的数据容器：文字、整数、小数、有顺序的一组值、带标签的资料集合、固定的一组值。
