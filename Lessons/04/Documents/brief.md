# Lesson 04 - 把代码整理成函数：定义、参数与返回值

## 章节定位

这是 Coding Club 的第四节正式课。学生已经能够使用变量、输入、条件判断和循环；本节开始学习如何把一组有名字的步骤整理成函数，让代码更容易阅读、重复使用和修改。

课程从不带参数的简单函数开始，再加入参数和返回值。学生会把 Lesson 03 中的条件和循环放进函数，完成一个由多个函数组成的互动挑战程序。

## 本节概览

| 项目 | 内容 |
|---|---|
| 建议时长 | 60 分钟 |
| 主题 | `def`、函数调用、参数、`return`、函数复用 |
| 核心产出 | 一个使用多个自定义函数的 Function Challenge |
| 先备知识 | 能运行 Python，使用变量、`input()`、`int()`、条件和循环 |
| 下一节衔接 | 使用模块和库，把程序拆分成可复用的文件 |

## 学习目标

到课末，学生能够：

1. 使用 `def` 定义一个函数。
2. 调用自定义函数，并说明函数定义不会自动执行。
3. 使用参数让同一个函数处理不同的数据。
4. 使用 `return` 把结果交回调用函数的代码。
5. 区分 `print()` 和 `return` 的用途。
6. 把条件判断或循环整理成一个函数。
7. 独立完成一个包含多个函数的互动程序。

## 成功标准

- 程序至少定义 3 个自定义函数。
- 至少有 1 个函数带参数。
- 至少有 1 个函数使用 `return`。
- 主程序实际调用所有核心函数。
- 至少有 1 个函数包含条件判断或循环。
- 函数名和参数名能够说明用途。
- 程序能够从头运行到结束，没有未解决的报错。
- 学生能解释一个函数的输入、处理过程和输出。

## 教学重点与应对

| 诊断风险 | 本节应对 |
|---|---|
| 学生只会写函数定义，不会调用 | 每个函数定义后立即进行一次调用，并要求先预测输出。 |
| 把参数和变量混淆 | 用“函数外传入数据，函数内使用参数”的图示和小练习。 |
| 认为 `print()` 和 `return` 相同 | 对比一个只能显示结果、一个可以继续计算的例子。 |
| 函数缩进错误 | 让学生圈出函数体，并统一检查冒号和缩进。 |
| 学生提前完成 | 增加默认参数或更多函数调用，但不引入递归和复杂作用域。 |

## 教学边界

本节暂不展开：

- 递归函数；
- `*args`、`**kwargs`；
- 装饰器和生成器；
- 复杂的作用域规则；
- 类和面向对象编程；
- 异常处理。

## 形成性评估

- 课堂中：预测函数调用结果、补全参数、区分 `print()` 与 `return`。
- 中段检查：学生独立写出一个带参数并返回结果的函数。
- 课末：运行 Function Challenge，并完成 4 题 exit ticket。
- 记录：将学生标记为“独立完成 / 在提示后完成 / 尚需支持”，供下一节模块课分组使用。
