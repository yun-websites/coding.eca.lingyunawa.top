# Daniel 的个人编程任务计划：随机漫步模拟器

## 项目概览

**项目名称：** 随机漫步模拟器（Random Walk Simulator）  
**适合对象：** 能编写基础 Python 程序、使用简单标准库（如 `math`、`random`）的单人学生  
**预计时间：** 3–5 小时，可分 2–3 次完成  
**所需工具：** Python 3；仅使用 Python 标准库，不需要安装第三方库  
**最终成果：** 一个可从终端运行的程序，模拟二维随机漫步并报告行走距离等统计结果

## 项目目标

编写一个程序，让虚拟行走者从坐标 `(0, 0)` 出发。每一步随机选择上、下、左、右中的一个方向，走固定长度。程序执行用户指定的步数后，显示最终坐标、离原点的直线距离，以及本次模拟经过的总路程。

这个项目练习：

- 变量、数字运算与 `input()`；
- `if` 条件、`for` 循环；
- `random` 模块生成随机方向；
- 用 `math.sqrt()` 计算距离；
- 列表或计数器保存、汇总数据；
- 拆分函数、处理简单无效输入与测试程序。

## 功能要求

### 基础版本（必须完成）

1. 提示用户输入步数，并将输入转换为整数。
2. 从 `(0, 0)` 开始，进行指定步数的随机漫步。
3. 每步随机选择四个方向之一：上、下、左、右；每次移动一个单位。
4. 记录每一步的位置，或用清晰的方式累计所需统计数据。
5. 显示：
   - 实际行走步数；
   - 最终坐标 `(x, y)`；
   - 从原点到终点的直线距离，使用公式 `sqrt(x*x + y*y)`；
   - 本次总路程（基础版本中等于步数）。

### 扩展功能（基础版本完成后再做）

- 允许用户指定每一步的长度。
- 显示每个方向分别走了几步。
- 计算漫步过程中离原点最远的距离。
- 让用户选择重复模拟次数，并报告平均终点距离、最远和最近的终点距离。
- 提供可选随机种子，使测试时能重复得到相同结果（可探索 `random.seed()`）。

## 建议实现步骤

1. **拆解问题：** 确认需要保存的状态，例如 `x`、`y`、总步数和每步位置。
2. **处理输入：** 读取步数并转换成整数；拒绝非正数或非整数输入，或明确说明程序只接受正整数。
3. **实现单步移动：** 使用 `random.choice()` 从四个方向中抽取一个方向，并更新坐标。
4. **重复移动：** 用循环执行单步移动，次数由用户输入决定。
5. **计算结果：** 用 `math.sqrt(x ** 2 + y ** 2)` 计算起点到终点的直线距离。
6. **输出结果：** 标签清楚、格式易读地打印统计数据。
7. **自行测试：** 测试小步数、较大步数、无效输入，并检查每一步位置是否只改变一个坐标单位。
8. **添加一个扩展功能：** 从上面的扩展清单中任选一项，并在说明中描述它的实现方式。

## 可选设计提示（不提供完整解答）
